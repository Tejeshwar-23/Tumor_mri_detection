# Brain Tumor Detection from MRI Images

This project is a deep learning based web application for detecting brain tumors from MRI images. The trained model is integrated with a Flask application, allowing users to upload an MRI image and receive a prediction.

## About the Project

The project focuses on using deep learning for medical image classification. MRI images are processed and passed through a trained neural network model to classify the input image.

The trained model is saved as `brain_tumor_model.h5` and is used by the Flask application for making predictions.

## Features

* Upload MRI images through a web interface
* Preprocess the uploaded image
* Predict the presence of a brain tumor using the trained model
* Display the prediction through the web application
* Model evaluation using accuracy, F1-score and confusion matrix
* Flask-based web interface
* Deployment-ready application

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Tejeshwar-23/Tumor_mri_detection.git
cd Tumor_mri_detection
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Flask application:

```bash
python app.py
```

The application can then be accessed through the local URL shown in the terminal.
